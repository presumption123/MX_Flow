# Deviations from the original

Every intentional difference between this project and Halcyon Flow / Halcyon Docs 1.0.4.

Gate G6 fails any observable difference that is not recorded here. Builders do not edit this file
directly — a Builder that believes it needs a deviation stops and reports it, and the Orchestrator
records it after the Verifier agrees it is genuinely necessary.

Format: one row per deviation. Keep `Why` short and concrete.

| # | Area | Original | Ours | Why | Decided in |
|---|------|----------|------|-----|-----------|
| 1 | CRDT | Yjs (`yjs`, `y-prosemirror`, `y-protocols`, `y-websocket`) | Loro (`loro-crdt`, `loro-prosemirror`) | CardMirror ships working Loro collaboration with ~200 KB of schema-aware merge-repair logic and ~30 test files. Porting to Yjs discards all of it to change something no user can observe. | `DECISIONS.md` §D2 |
| 2 | App-to-app transport | ~20 `superflow:*` Electron IPC channels | `cardmirror-bridge` loopback HTTP | CardMirror's bridge is already built, documented, frozen, and security-reviewed, and staying on it keeps us interoperable with upstream. Both designs are loopback HTTP anyway. | `DECISIONS.md` §D3 |
| 3 | Icon set | Untitled UI | Lucide or Feather | Untitled UI icons may not be redistributed even in modified form. A distribution blocker, not a preference. | `DECISIONS.md` §D1 |
| 4 | Renderer framework | React 18/19 + zustand | Vanilla TypeScript | We extend CardMirror, which uses no UI framework. Adding React to match Halcyon's internals would fork us off upstream for no user-visible gain. | `DECISIONS.md` §D3, `00-MASTER-PLAN.md` §3 |
| 5 | `.cmir` UTI declaration | `UTTypeConformsTo: ["public.data", "public.zip-archive"]` | `public.data` only | Halcyon's declaration is simply wrong — `.cmir` is gzipped JSON, and its own reader sniffs the gzip magic bytes. Copying the error would mislead the OS and other tools. | `DECISIONS.md` "Corrections" |
| 6 | Round file extension | `.jflow` | `.mxflow` | Avoids colliding with the original's file association when both are installed. The on-disk JSON is field-for-field identical. | `00-MASTER-PLAN.md` §4 |

## Not deviations

Recorded because they get mistaken for deviations during review.

- **Flat `pocket`/`hat`/`block` headings.** Looks like a missing tree structure; it is deliberate,
  in both CardMirror and Halcyon, because that is how Word stores headings in OOXML. The outline
  hierarchy is derived at render time. Do not "fix" it.
- **`live_view` emitting no content hole in `toDOM`.** Intentional — it is what makes the node
  read-only.
- **Fixed 200-slot row arrays.** Not a placeholder or a scaling oversight. The original does this,
  and the format depends on it.
- **`CellValue` being `string | Cell`.** The writer deliberately collapses unstyled cells back to
  bare strings, so real files contain both. Normalizing to objects would break compatibility.
- **No PDF or HTML export.** The original has neither. "PDF" appears only in its prose and
  `text/html` only in clipboard serialization.
- **Excel export dropping rich text.** Upstream exports raw text by design — tags and blocks as
  plain text, cards as text content, with no bold, underline, or highlight.
